# Carbon Black

> Carbon Black is an endpoint security company, now part of Broadcom (formerly VMware Carbon Black). Its cloud-native platform delivers next-generation antivirus, endpoint detection and response (EDR), threat hunting, live query, and application control. The Carbon Black Cloud developer network publishes REST APIs, a Python SDK, and integration guides. APIs authenticate with an API Id/Secret pair passed in an X-Auth-Token header against region-specific Carbon Black Cloud hostnames.

## APIs

- [Carbon Black Cloud Platform API](https://developer.carbonblack.com/reference/carbon-black-cloud/platform-apis/): REST APIs for Endpoint Standard, Enterprise EDR, Audit and Remediation (live query), and Workload/Container protection. Base host (Prod 02): https://defense.conferdeploy.net
